Connecter mon bot WhatsApp

Saisis ton numéro, tu reçois un code à entrer dans WhatsApp.

Avec l’indicatif du pays, sans +, sans espaces ni zéro initial.

Ton code de connexion

  1. Ouvre WhatsApp, puis Appareils connectés.
  2. Touche Connecter un appareil.
  3. Choisis Connecter avec le numéro de téléphone et saisis le code.

Le code expire au bout de quelques minutes. Une fois saisi, envoie !ping dans n’importe quelle discussion pour tester.
